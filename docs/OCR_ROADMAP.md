# OCR roadmap — proposed, not implemented
Preserve working two-class YOLOv5s SiLU INT8 RKNN, 640x640, 1920x1080 streaming. Add separate lightweight LPRNet recognition context; Rockchip lists RV1106 INT8 support at https://github.com/airockchip/rknn_model_zoo/tree/main/examples/LPRNet . Verify compatibility with existing toolkit/runtime 1.6.0 before integration. Typical input 94x24, inspect actual model shape and normalization. Official pretrained Chinese plate model is a technical smoke test, not validated Pakistan recognizer. Fine-tune on consented/authorized plate crops with A-Z, 0-9 plus CTC blank, explicit handling of two-line plates. Crop original-resolution frame using inverse letterbox and clipping; rectify if needed, never crop from 640 image if original available. Separate contexts, serialized NPU calls, bounded crop queue, OCR on selected high-quality crops only, temporal consensus, reject uncertain output. No FPS or memory guarantee. First standalone OCR inference, then dual-model memory/CMA and VENC test at confirmed 1080p; measure exact plate match, character error rate, latency and recall. Do not publish plate images or identifiers to public repository. No code or model compiled yet.
